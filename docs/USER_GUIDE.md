# 使用指南

## 1. 安裝與首次啟動

mini台灣電台支援 Android 8.0（API 26）以上裝置。目前專案尚未提供預建 APK 或公開 Release，需依 [`DEVELOPMENT.md`](DEVELOPMENT.md) 自行建置。安裝 APK 後開啟 App，即可從內建資料顯示可用電台。

Android 13 以上會要求通知權限。允許通知後，背景播放時可顯示媒體通知與播放控制；拒絕權限不影響前景畫面的基本播放，但通知呈現可能受系統限制。

## 2. 主畫面

主畫面包含：

- App 標題「mini台灣電台」及副標題「把台灣電台帶著走」。
- 右上角設定按鈕。
- 電台卡片清單。
- 播放時顯示於底部的迷你播放器。

每張電台卡片會顯示名稱，以及聯播網、頻率與地區等可用資訊。沒有直播網址或尚未開放的電台會顯示「準備中」，無法播放。

## 3. 播放與停止

1. 點選電台卡片右側的播放按鈕。
2. App 顯示「正在連線...」。
3. 串流開始後顯示「播放中」，播放中的卡片具有主題色外框。
4. 點擊播放中卡片右側或迷你播放器中的停止按鈕即可停止。
5. 播放其他電台時，App 會直接切換直播來源。

若串流失效、網路中斷或格式無法播放，畫面會顯示「串流暫時無法播放」，App 不會因此關閉。

## 4. 迷你播放器

選定電台後，主畫面底部顯示迷你播放器：

- 第一列顯示「現正播放」與連線／播放狀態。
- 第二列顯示電台名稱。
- 右側提供停止按鈕。
- 點擊電台資訊區域，清單會捲動到目前播放的電台。

迷你播放器會避開 Android 導覽列。

## 5. 最愛電台

點擊電台卡片上的空心愛心可加入最愛。加入後會顯示「電台名稱已加入最愛」，愛心變為淺紅色，該電台移至一般電台之前。

再次點擊愛心可取消最愛。最愛狀態與順序會儲存在裝置中，重新啟動 App 後仍會保留。

## 6. 調整最愛順序

1. 長按已加入最愛的電台卡片。
2. 卡片放大並提高陰影後，上下拖曳到目標位置。
3. 放開手指完成排序。

只有最愛電台可以拖曳，且不能拖入一般電台區域。排序變更會立即儲存在裝置中。

## 7. 背景播放

- 按 Home 回到桌面後會繼續播放。
- 鎖定螢幕後會繼續播放。
- 可透過系統媒體通知或鎖定畫面控制播放。
- 從最近使用的 App 清單移除 App 時，播放服務會停止並移除通知。
- 重新開啟 App 不會自動播放上次電台。

## 8. 設定

點擊主畫面右上角齒輪進入設定頁。左上角返回箭頭或 Android 系統返回鍵可回到主畫面。

### 8.1 顯示模式

- 系統：跟隨裝置設定。
- 淺色：固定使用淺色模式。
- 深色：固定使用深色模式。

選擇後立即套用並儲存。

### 8.2 主題色

可選擇六個預設色彩，或拖動 Hue 彩色滑桿設定自訂色。主題色會立即套用至按鈕、播放外框及其他重點元件。

### 8.3 更新電台清單

點擊「更新電台清單」可從 GitHub Pages 下載最新資料：

- 更新期間顯示「更新中...」，按鈕暫時停用。
- 成功時顯示可見電台數量，不計入 `noshow: true` 的資料。
- 失敗時保留目前清單並顯示失敗訊息。

App 不會在已有本機清單時自動更新；需要最新資料時請使用此按鈕。

遠端更新依賴 GitHub Pages 已正確部署。若發布網址尚未啟用或暫時無法連線，手動更新會失敗並保留目前資料。

## 9. 常見問題

### 電台一直顯示正在連線

可能是網路不穩、電台伺服器忙碌或串流網址已變更。可先停止播放，稍後再試或切換其他電台。

### 為什麼有些電台顯示準備中

該項目可能尚未提供有效直播網址，或資料中的 `enabled` 設為 `false`。

### 為什麼重新開啟 App 沒有繼續播放

這是預期行為。App 會保留最愛與外觀設定，但不會自動恢復上次播放。

### 清除 App 資料後會發生什麼

遠端清單快取、最愛順序、顯示模式及主題色都會被清除，App 將回到內建清單與預設設定。
