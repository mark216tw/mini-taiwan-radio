# 測試計畫

## 1. 目的

本文件定義 mini台灣電台在開發、回歸與發布前應完成的測試。專案目前尚未建立自動化測試，因此以下項目以手動測試為主，也作為後續單元測試與裝置端測試（instrumented tests）的實作清單。

## 2. 建議測試環境

至少涵蓋：

| 類型 | 建議環境 |
|---|---|
| 最低版本 | Android 8.0／API 26 |
| 通知權限 | Android 13／API 33 |
| 前景服務規則 | Android 14／API 34 |
| Target SDK | Android 15／API 35 |
| 導覽模式 | 手勢導覽、三鍵導覽 |
| 顯示模式 | 淺色、深色、跟隨系統 |
| 網路 | Wi-Fi、行動網路、離線、不穩定網路 |

應至少包含一台實機，串流、通知及背景限制不應只以模擬器判斷。

## 3. 建置驗證

- Gradle Sync 成功。
- `:app:assembleDebug` 成功。
- `:app:assemblePrerelease` 成功，且執行 R8 與資源縮減。
- APK 可安裝於 API 26 以上裝置。
- App 啟動不閃退。
- 檢查輸出 `app/build/outputs/apk/debug/app-debug.apk`。
- 檢查測試發行輸出 `app/build/outputs/apk/prerelease/app-prerelease.apk`。
- 確認 Pre-release APK 版本為 `1.0.0-prerelease`，並使用 Debug 憑證簽署。

## 4. 電台資料

### 初始載入

- 有有效快取時直接顯示快取，不自動連網。
- 沒有快取但 assets 有資料時顯示內建清單，不自動連網。
- 快取損壞時改用 assets。
- 快取與 assets 均無可見資料時才嘗試遠端下載。
- 所有來源失敗時顯示無資料／錯誤，不閃退。

### JSON 解析

- 必要欄位 `id`、`name` 可正常解析。
- 選填字串缺少時使用空字串。
- 缺少 `enabled` 時預設為 `true`。
- 缺少 `noshow` 時預設為 `false`。
- `noshow: true` 不進入畫面。
- `enabled: false` 顯示「準備中」。
- 空 `streamUrl` 顯示「準備中」。

### 手動更新

- 按下後顯示「更新中...」且按鈕停用。
- 成功後立即更新主畫面與快取。
- 成功數量不包含 `noshow: true`。
- 下載、HTTP 或 JSON 失敗時保留目前清單。
- 重複快速點擊不會建立多個並行更新。

## 5. 播放

- MP3 串流可播放。
- AAC 串流可播放。
- HLS／M3U8 串流可播放。
- HTTP 與 HTTPS 串流皆依目前設定運作。
- 點擊其他電台會切換來源。
- 連線時顯示「正在連線...」。
- 播放後顯示「播放中」。
- 失敗時顯示「串流暫時無法播放」。
- 失敗不造成 App 閃退。
- 停止後迷你播放器消失，服務及通知終止。

## 6. 背景與生命週期

- 按 Home 後繼續播放。
- 鎖定螢幕後繼續播放。
- 媒體通知顯示正確電台名稱。
- 通知／鎖定畫面控制可操作播放器。
- Android 13 以上允許與拒絕通知權限皆不閃退。
- Activity 重建時檢查畫面與實際播放狀態是否一致。
- 從最近使用清單移除 App 後停止播放、服務與通知。
- 重新開啟 App 不會自動播放。

## 7. 最愛與排序

- 加入最愛後愛心變色、移到前方並顯示正確 Snackbar。
- 取消最愛後回到一般電台區，且不顯示加入訊息。
- 關閉及重新啟動後最愛仍存在。
- 遠端資料移除或隱藏某 ID 後，無效最愛會被清理。
- 非最愛項目維持 JSON 原始順序。

### 拖曳回歸

- 第一個最愛向下排序時，清單 viewport 不上移。
- 第二個最愛越過第一個時，新第一項完整可見。
- 第一項向上拖曳不會超出頂部或累積負位移。
- 最後一個最愛向下拖曳不會進入非最愛區。
- 快速跨越多個項目後順序正確。
- 拖曳期間卡片跟隨手指，其他卡片使用排列動畫。
- 放手後沒有二次跳動。
- 重新啟動後保留排序。

## 8. UI 與設定

- 主畫面與設定頁不與狀態列、導覽列重疊。
- 迷你播放器避開導覽列。
- 播放中的卡片只有外框改色，背景維持一般樣式。
- 系統、淺色、深色模式立即套用並保留。
- 六個預設色可選擇且勾選狀態清楚。
- Hue 彩色滑桿拖曳時即時更新主題。
- 自訂主題色重新啟動後保留。
- 狀態列與導覽列圖示在深淺背景下可辨識。
- 系統字體放大後文字、按鈕及卡片不嚴重裁切。
- 橫向、不同螢幕尺寸及 RTL 開啟時沒有崩潰。

## 9. 無障礙

- TalkBack 可讀出設定、最愛、播放與停止按鈕。
- 焦點順序符合視覺順序。
- 色彩不是唯一的播放或選取狀態提示。
- 觸控目標可操作且圖示不裁切。
- 拖曳排序目前缺少非手勢替代方案，列為後續改善項目。

## 10. 建議自動化測試

### 單元測試

- JSON 預設值及 `noshow` 過濾。
- 快取／assets／遠端優先順序。
- 遠端失敗不覆蓋有效資料。
- 最愛新增、刪除、清理與重排。
- 顯示模式及色彩持久化。

### Compose UI 測試

- 加入最愛 Snackbar。
- 播放、停止與準備中狀態。
- 設定頁返回與即時主題切換。
- 手動更新成功／失敗訊息。
- 第一項附近的拖曳排序回歸。

### 服務與整合測試

- ACTION_PLAY／ACTION_STOP。
- MediaSession metadata。
- task removed 停止行為。
- Activity 重建與既有播放狀態同步。

## 11. 發布驗收

- 第 3 至第 7 節列為 P0 發布阻斷案例，必須全部通過。
- 第 8 至第 9 節列為 P1 品質案例；若未通過，必須記錄影響、替代方式與發布決策。
- 每個可見且 enabled 的電台完成實機播放抽查。
- 沒有阻斷性閃退、ANR 或背景服務錯誤。
- 權限與隱私說明符合實際行為。
- versionCode、versionName、圖示及簽章正確。
- 已確認電台資料來源與使用授權。
